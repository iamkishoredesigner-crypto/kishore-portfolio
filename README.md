# Kishore L. — Product Design & AI Portfolio

A responsive, dependency-light portfolio website for Kishore L., positioned around Product Design, AI UX, enterprise products and hands-on development.

## Run locally

Open `index.html` directly in a browser, or run a simple server:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## Before publishing

1. Replace `your.email@example.com` in `index.html` with the real email address.
2. Replace the LinkedIn URL with the real profile URL.
3. Add your resume as `resume.pdf` in this folder.
4. Replace the abstract project visuals with approved screenshots/mockups if desired.
5. Review every project statement and add only verified metrics/outcomes.

The site is intentionally static so it can be deployed to GitHub Pages, Netlify, Vercel, or any standard web host without a build step.
